# 🤖 FluffelTools

A versatile, no-AI Python productivity suite built with Streamlit. It combines e.g. a custom calculator, vocabulary trainer, interactive quiz master, and a chart generator into one unified dashboard. Focused on pure programming logic, clean data processing, and efficient state management.

![Python](https://img.shields.io/badge/Python-3.11+-blue)
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://fluffeltools.streamlit.app/)
![License](https://img.shields.io/badge/License-MIT-yellow)

## ✨ Functions

- Calculator
- Interest Calculator
- Chart Generator
- Vocabulary Trainer (Work in Progress)
- Unit Converter (Work in Progress)
- Password Generator
- Weather App (Work in Progress)

## ⚙️ Setup

### 1. Clone repository
```bash
git clone https://github.com/Flockemon24/FluffelTools.git
cd FluffelTools
```
### 2. Install dependencies
```bash
pip install -r requirements.txt
```
### 3. Run app and open in browser
```bash
streamlit run main.py
```
Im Browser:
http://127.0.0.1:8501/
